# 闪念间雾化标记语法

> 适用范围：`In a Flash` 闪念间的历史报名数据导入管线（R16a/KTD4）。
> 读者：运营方在平台外跑的离线雾化 agent（人或 LLM），以及导入脚本的
> 维护者。本页是**唯一规范**——解析器（`backend/lib/cgc_2046/flashback/fog_markup.ex`）
> 与离线 agent 共用同一约定，改动语法必须同 PR 改本页与解析器。

## 为什么需要标记语法

当年报名的原文**永远不改写**（档案真实性）；对外展示（校友墙/分享卡/公开页）
按「雾面区间」遮蔽——形态在（"这里有一段当年写的话"）、内容藏。平台
**不内置任何 AI**：雾化判断在平台外完成（运营方私下用外部 agent 处理），
产出**带标记的文本**交给导入脚本，脚本解析标记入库：

```
原始列值（已打标）            解析入库
──────────────────────      ──────────────────────────────
"我在⟦盛大做测试⟧，想        raw_text = "我在盛大做测试，想亲眼看看是不是。"
亲眼看看是不是。"            fog_spans = [%{"start" => 2, "len" => 5}]
```

- `raw_text`：剥离全部标记符的完整原文（本人视图永远完整，永不再改）；
- `fog_spans`：区间列表，`start`/`len` 为 **grapheme 偏移**（见下）。

## 语法

### 定界符

| 符号 | 码位 | 名称 |
|---|---|---|
| `⟦` | U+27E6 | MATHEMATICAL LEFT WHITE SQUARE BRACKET |
| `⟧` | U+27E7 | MATHEMATICAL RIGHT WHITE SQUARE BRACKET |

选这两个符号的原因：2012-2018 年报名自由文本的实际字符集（中文、标点、
手机号、邮箱、论坛风英文）中**不出现**数学白方括号，杜绝与正文歧义。
不要用 `[]`、`**`、`~~` 等正文可能出现的符号。

### 区间

用 `⟦ … ⟧` 包住要雾掉的内容：

```
我是在校学生，⟦在盛大做测试⟧，想亲眼看看是不是。
```

### 可选 reason（原因标注）

标记内**第一个竖线 `|`** 之后是原因（自由文本，可再含 `|`），入库随 span
保存，供运营复核雾化决策：

```
我是在校学生，⟦在盛大做测试|雇主名⟧，想亲眼看看是不是。
```

reason 可省略。**内容里要出现字面 `|` 时**：把含 `|` 的部分单独成段雾化，
或接受它被当作分隔符（内容截断到第一个 `|` 之前）——离线 agent 应避免
在非 reason 位置输出 `|`。

### 转义

标记内外规则一致：

| 输入 | 输出（入库 raw_text） |
|---|---|
| `⟦⟦` | `⟦`（字面） |
| `⟧⟧` | `⟧`（字面） |

正文确实需要字面 `⟦`/`⟧` 时（几乎不会有）用它。

### 禁止（fail-closed，导入直接报错到 dry-run 报告）

- **未闭合**：`⟦内容` 没有 `⟧` → `unclosed_marker`；
- **嵌套**：标记内再出现单个 `⟦` → `nested_marker`；
- **空区间**：`⟦⟧` 或 `⟦|只有原因⟧`（内容为空）→ `empty_span`。

错误不会静默丢字：dry-run 报告按行/列出错位置，修正后重跑。

## 坐标约定（grapheme 偏移）

`start`/`len` 按 **Unicode grapheme（字素簇）** 计数——与用户感知的"字符"
一致（`String.length/1` 口径）。例：

```
文本：我在盛大做测试
      ↑     ↑
      0     2        （"我"=0，"在"=1，"盛"=2 …）
span：{"start": 2, "len": 5}   → 遮蔽「盛大做测试」
```

- 中文/英文/数字每字 1；emoji 组合序列（👩‍💻）按 1 计；
- 区间相对**剥离标记后的 raw_text**（不是带标原文）；
- 区间必须**有序不重叠**、不越界（`start + len ≤ 总长`）——解析器按顺序
  产出天然满足；结构复核单源在 `Cgc2046.Flashback.FogSpans.validate/2`。

## 哪些内容该打标（给离线 agent 的指引）

打标的对象是**当年自由文本列**（自我介绍/有意思的事/备注/社交媒体等），
遮蔽今天仍可定位到人的信息：

- 现职雇主/单位名（当年的职业学生无所谓，写明现在的公司才是泄露）；
- 手机号/微信号/QQ 号/邮箱（正文里出现的）；
- 精确住址、学校全名 + 年级组合；
- 可唯一定位的他人姓名（"和某某一起报名"）。

**结构化列（姓名/手机/邮箱）不要打标**——导入脚本对它们**自动整段雾化**
（`fog_spans = [%{"start" => 0, "len": 全长}]`），离线 agent 处理它们是浪费。

## 验收口径（导入 dry-run 报告）

每次导入的 dry-run 报告（`mix flashback.import <path>`，不加 `--commit`）
必须满足：

- `fog.residual_markers = 0`：入库 raw_text 无任何残留 `⟦`/`⟧`；
- `fog.invalid_spans = 0`：全部 spans 通过 `FogSpans.validate/2`
  （结构/重叠/越界单源校验）；
- 标记解析失败的行列会以 `{:fog_markup, 行, 列键, 原因}` 报错中止——
  修正源文件后重跑，不允许跳过。

## 完整示例

输入（自我介绍列，已由离线 agent 打标）：

```
⟦我叫王小明，手机 138 0013 8000|正文含联系方式⟧大家好！我是⟦北京邮电大学大三⟧的学生，
想学前端。微博：⟦http://weibo.com/wxm_example|社交账号⟧，欢迎交流。
```

解析结果：

```json
{
  "raw_text": "我叫王小明，手机 138 0013 8000大家好！我是北京邮电大学大三的学生，想学前端。微博：http://weibo.com/wxm_example，欢迎交流。",
  "fog_spans": [
    {"start": 0,  "len": 21, "reason": "正文含联系方式"},
    {"start": 27, "len": 9},
    {"start": 51, "len": 30, "reason": "社交账号"}
  ]
}
```

（len 数值以实际 grapheme 计数为准，此处示意。）
