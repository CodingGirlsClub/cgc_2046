## 翻译原则

1. zh 为 source，en 初稿为 AI 翻译（本 PR 上线门槛），措辞简洁专业，非逐字直译。
2. 按钮/CTA 用动词短语（Sign in / Create account / Continue to pay）。
3. 同一概念全站统一（参见本表），避免同义词漂移。
4. 富文本占位（`{var}` / `<tag>`）保留占位语法，翻译时不破坏。
