# Hacker Start 1024 文案包 v1（builder 叙事）

2026-09-30 · 来源：创始人 + 顾问 brainstorm（builder 叙事转向建议）→ 创始人逐条裁决

## 决策记录（本次新增，session-settled）

- **主线：学员 → builder。** 叙事后置从「学会了什么」改为「做出了什么」；学员身份升级为 builder（有想法、把它做出来的人）。
- **Agent 保持主角**（裁决修正：不退到幕后）——builder 用 Agent build；统一话术「你和你的 Agent」。
- **组织名与 campaign 名都不动**，builder 化只发生在叙事与文案层；「跟上时代」用故事讲：十年，我们换了一个动词——从 coding 到 building。
- **Event 标题禁序号**：同城多场同名（`Hacker Start 1024 · {城市}`），靠时间与地点区分；加序号有排名嫌疑。主题场不设规则——届时需要，直接在活动名称里改即可。
- **「看上一场作品」类话术禁用**：首批没有上一场，开场 15 分钟改为从作品选题库选题。
- **选题库 × 许愿树回灌**：选题库没有想要的 → 去「许愿树」（闪念间）提交期望；教程研究员把高频愿望回填为选题库 v2 候选。
- **话语分渠道**：builder 话术只用于参与者/传播面；教程研究员（Tutor）招募仍讲工程质量，两声道不混。
- **hero 顶部 slogan 胶囊顶替招商 slot**（视觉验收轮增补）：原「CGC × 你的品牌」招商占位胶囊被读成「未完成」——保留胶囊样式、更名为 **initiative slogan**，内容用十周年脊柱句「十年，我们换了一个动词：code → build」（语言修正：coding/building 是动名词不是动词，改用动词原形坐实「换动词」）；副标下的 builder 宣言撤下（由 slogan 顶替），builder 身份叙事由 why 段标题与 15 分钟开场卡承载。
- **「50+ 场线下工作坊」全站统一改 45+**（对账发现，视觉验收轮增补）：闪念间档案共 47 场（2012-2019.09，其中 17 场为 2016 前 Rails Girls 血缘期），与「50+」（2016-2025 历史累计口径）相抵；45+ 有档可查。同步面：落地页数字带（zh/en）、campaign 十年带（zh/en）、小程序浓缩段、落地页测试断言。遗留口径点：档案地名达 15 个 vs 页面「10 城」属不同口径（累计足迹 vs 常态网络），如再被质疑需加标注——本轮不动。
- 本包对 2026-09-18 campaign plan 的 hero / why / 开场卡文案构成**定点 supersede**（plan 文档为历史快照，不回改；以本文为准）；其余 plan 决策不受影响。

## 已定稿 · 4 课程包（教程研究员输入文档，v1）

**定位**：Hacker Start 不是一门编程课——是你和你的 Agent 的第一个 build 现场。

**学员画像**：有想法、没代码的人（产品经理 / 运营 / 设计师 / 大学生 / 小创业者）。他们不叫学员，是 builder。

**成果承诺（合同式）**：3 小时后，每人拥有一个能点开、能演示、能发给朋友的作品。

**节奏表（对外 15/120/30，对内教学目标）**

| 环节 | 对外文案 | 教练教学要点 |
| --- | --- | --- |
| 15 开场 | 从作品选题库选定今天要 build 的东西 | 帮每人把选题压到 3 小时可交付；教练核对可行性 |
| 120 动手 | 你说，Agent 写 | 三轮「描述 → 看结果 → 修正」；只问「你想让它做什么」，不代写 |
| 30 Demo | 人人上台，作品投屏 | 每人 90 秒；拍「作品 + 作者」合影（社媒素材） |

**作品选题库 v1**（每题均过三关：带得走＝离开能继续用 / 发得出＝有分享时刻 / 跑得起来＝现场可演示）

1. 个人数字名片页——你的第一个作品；纯前端、最快出活，首推
2. 「给爸妈的」家庭相册——情感钩子，天然带来家庭二次传播
3. 活动报名页——下一场聚会直接能用上
4. 喝水/读书打卡小工具——日用留存型，本地存储即可跑
5. 小店菜单页——小商户学员刚需，手机端体验完整
6. 旅行计划生成器——demo 效果最炸；接不了真实数据时降级为示例数据
7. 自带选题——预审线：一句话说清想要什么 + 有可演示的静态版本

**许愿树回灌机制**：选题库没有想要的 → 去许愿树提交期望（小程序「程序媛汇」底部「闪念间」→ 许愿树；网站导航同入口）；教程研究员定期把高频愿望回填为选题库 v2 候选。

**教学暗线（对内不对外）**：学员真正学会的不是某个工具，是「说清楚你想要什么」——三轮描述-看-改即课程主干。

**两条红线**：选题与教程不出现任何厂商/工具名；现场部署与托管路径属运营 SOP，不写进课程文案。
