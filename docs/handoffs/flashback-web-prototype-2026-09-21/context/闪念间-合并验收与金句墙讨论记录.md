## 五、名册权限模型澄清（以代码为准）

| 层 | 谁能看 | 条件 |
|---|---|---|
| 统计数字（102 位） | 任何人（含陌生人） | 无 |
| 结构化名册（王\*\* · 城市 · 年份 · 当年职业） | 名册成员（attended 且回来认领） | 不要求自己寄出 |
| 内容层（雾化答案 + 今天摘要） | 名册成员 | **对方**已寄出才投出；对方撤回即刻收回 |
| 金句墙 / 分享卡 / 实名档案页 | 任何人（含陌生人） | 每条均有本人显式授权 |

要点：

- 「名册 vs testimony」是两个东西：名册受隐私铁律保护（出席记录的**枚举权**，靠 cohort 对等披露），不能公开；金句墙等是个人单点授权的公开物，天然可给陌生人看。
- 观看侧没有「自己寄出才能看」的门槛——「自己寄出」是供给端动作（点亮今天格 + 自己的内容层对别人开放），不是观看门票。
- 名册实际对全部名册成员开放全部 18 场（「同场」的准确含义 = 同在这批名册里的人）。
- 金句墙 = testimony 墙：作者限名册授权者（陌生人能看不能写），跨全部场次，涌现排序（点赞优先），SQL 层只出最热 60 条。

## 六、金句墙 Voices：从「长廊部件」到「独立公开面」

### 可供性分析（关键转折）

可供性 = 物件「邀请人做什么」。长廊/名册是**向内空间**（邀请认领、显影、写今天，有身份门槛）；金句墙是**向外空间**（邀请读、被戳中、点赞、转发，零门槛）。把向外橱窗塞进向内胶囊，两边可供性都被稀释——所以金句墙**独立成面**，不基于长廊。

独立可供性闭环：**读（被戳中）→ 赞（零成本）→ 分享 →「我也报过名？」找回转化**。每一环对路人开放，无一环要求身份。

### 已拍板的决策

- **Web**：独立页 `/flashback/voices`（命名：voices 优于 golden-quote / one-liner——「不是名言佳句，是当年的人留下的声音」）；header 加公开入口；落地页金句 section 改为**随机几句 +「看全墙 →」**导流（非精选）。
- **小程序**：不给 tab 权重；走**发现页入口卡 + 每张分享卡/金句卡自带「看全墙」**（裂变自携带入口）。
- **点赞不强制登录**：匿名点赞已实现（`web/lib/flashback-voter.ts` localStorage 设备级 voter_key，后端唯一索引去重）。登录墙会杀死 90%+ 的赞，而赞是涌现排序的燃料。转化钩子挂高意图动作（找回档案本来就需要身份），赞后给不打断的轻提示。
- **唯一 KPI = 被转发**。

### 视觉语言选型（A/B/C/D 四方向原型）

- 原则：金句墙与许愿树（Wishes，山河脉络/地图语言）**对仗而非同款**，避免互相稀释。
- **A 单句影院**（一屏一句慢读，赌情感峰值）、**B 证言橱窗**（卡片墙，赌规模震撼）、**C 山河图谱**（地图城市结点）、**D 星空**（选定语言线：「星光是很多年前发出的光，今天抵达你」——年份聚成星座、点赞定星亮、偶有流星；与山河天/地对仗零稀释，且「对星许愿」与 Wishes 白捡双关）。
- 技术选型调研结论：**C 用 ECharts**（Apache-2.0，geo + effectScatter 涟漪 + lines 流动脉络；唯一可同构到小程序 ec-canvas 的生产路径；中国地图 geojson 用 DataV GeoAtlas 简化内联，**南海诸岛 feature 必须保留**）；**D 手写 Canvas 2D**（数据驱动确定性布局，粒子库全是短板；唯一双端同构路径）。
- 当前状态：第一版原型已完成（5 变体含 E 入口导流），C/D 视觉被否，已生成带调研结论的实施提示词，将由另一个 agent 重做 A-D 至「可直接发布」水准，且每变体补**桌面宽屏视口**。

## 七、许愿树 Wishes（已建 issue #791，分期实施）

- **概念**：金句回望（过去）、许愿前望（未来），两个公开面讲清「这些人是谁」和「这些人要什么」。
- **命名闭环**：Voices（过去的声音）→ Wishes（未来的愿望）→ **Echoes 回响**（愿望被众人附议、被应答成场的那一刻；中文取「念念不忘，必有回响」的现成心智，不叫「响应」）。
- **授权语义（必须先解决的障碍）**：今天愿望的「公开」= 公开给名册成员，用户心智不含陌生人。改为两档：**私密 / 公开**（公开明示「所有人可见，包括没参加过活动的人」）；公开下可选匿名（姓\*\* · 城市）/ 实名。存量愿望需重新征询。
- **实名用什么**：读既有 `User.display_name`（选档 UI 明示「将以 display_name 实名展示」）。**不加 username、不加账号侧 realname**——无一落地功能消费；名册侧真名（`flashback_person.full_name`）已在被消费（名册展示/显影/找回核对/兑换打款核对），realname 永不上公开墙。
- **附议与回响**：旧「附议 = 订阅成场通知」机制已随行动板移除而死（附议只剩纯计数）。借「回响」复活：附议计数叙事为「N 人念念不忘」；admin 对高附议愿望点「回应/成场」→ 建真 Event → 附议者收「你的愿望有回响了」（`flashback_action_scheduled` 模板现成）。路人可「同感 +1」（匿名计数），**不能附议**（附议需微信订阅通道，硬开变假附议）。
- **形态方向**：不做字面的树——**地图山河脉络作树枝、不同城市的人发愿挂上去**（百家姓图谱感），愿望本就快照了城市字段。
- **节奏**：金句墙先上（有存量）；许愿树第二期，等愿望攒到不显冷清再开公开面。
