## 一、900 句怎么展示？——设计上就不是全量铺

先纠正一个前提：金句不是「每人自动出 3 句」，而是三重 opt-in 的漏斗——**回来认领 × 主动开金句授权 × 逐句圈选**的人才会上墙。pilot 阶段 344 人的场，能回来的几十人里再授权圈选，实际几十句量级。

但即使真到了 900 句，墙上也从来不是全量展示。刚查了后端实现（`public.ex` 的 `quotes/1`）：**涌现排序 = 点赞数优先、更新时间次之，SQL 层 `limit 60`**——900 句时墙上只浮出「最热 60 条」，其余沉底。注释原话就是「最热 60 条，而不是最新 60 条里再排」。

对三个变体的影响：I（横滑带）和 J（翻牌堆）天然是 top-N 容器；H 如果中选也不该把 60 条全织进去（18 个场次帧会被淹没），只织最热的三五条。

## 二、陌生人和同场者的本质区别——不是「内容清晰度」，是「名单枚举权」

你的观察是对的：**同场者看到的他人内容也是授权后的**（雾化答案、寄出者才可见）。但这恰恰是名册 gate 的真正含义——名册里唯一「未经逐条授权」的东西是**名单本身**：

| | 陌生人（路人态） | 同场 member |
|---|---|---|
| 统计数字（北京 102 位） | ✅ | ✅ |
| 金句墙 / 分享卡 / 实名页（个人单点授权） | ✅ 平等 | ✅ 平等 |
| **344 人的隐名名单**（王** · 上海 · 当年职业） | ❌ | ✅ |
| **互换内容层**（寄出者的雾化答案+今天摘要） | ❌ | ✅（且自己也寄出） |

本质区别在第三、四行：

1. **名册 = 出席记录的枚举权**。「谁报过 2014 北京场」这份名单，本人没有逐条授权公开——它只对同场可见，靠的是**对等披露**：名单上每个人都以同样方式暴露给彼此（你看得到我，我也看得到你）。把这份名单给陌生人，性质就从「cohort 内部对等可见」变成「把 344 人的出席记录出版到互联网」。这跟内容是否雾化无关，是枚举本身敏感。
2. **内容层 = 互换空间**。同场者看雾化答案的前提是「自己也寄出了」（reciprocity）——你把自己放上墙，才换得到看别人的资格。陌生人没有这个入场券。
3. **金句/分享卡/实名页 = 个人单点授权**。每一条都有本人显式的「这句可以公开」动作（授权档位、分享开关、credited 档），所以能给全世界看——陌生人看金句墙，**没有触碰**名册边界，因为墙里每一条都是本人签过字的。

所以你的问题「名册点不进去了，是吧？」——对，路人只能看到「102 位」这个数字，点不进名单；而「愿意公开的话」（金句）放进路人态恰恰**不破坏**这个模型，因为它从一开始就是授权公开物，不属于名册。

这也是为什么我建议文案改成双向表述：「名册只对同场的人可见——愿意公开的句子，都在这面墙上」——它把这条边界明明白白讲给路人听：什么不能看（名单），什么能看（授权金句），为什么。

这个模型你认的话，变体选择就没有授权层面的顾虑了，纯粹是形态手感问题。

## 可供性分析：金句墙和长廊是两个空间

可供性 = 一个物件「邀请人做什么」。用这个尺子量，我之前三个原型（H/I/J）有个共同的隐含错误：**都假设金句墙是长廊的部件**。

- **长廊/名册是向内空间**：它邀请的动作是认领、显影、写今天、看同场——「我是当年的人，我来找我自己」。有身份门槛，气质是私密、时间胶囊。
- **金句墙是向外空间**：它邀请的动作是读、被戳中、点赞、转发、「我也有故事」——「我不必是当年的人，我被这些人的话打动」。零门槛，气质是公开证言橱窗。

你的直觉（不基于长廊）是对的：把向外的橱窗塞进向内的胶囊，两边的可供性都被稀释——路人进长廊本来就没有可做的事（名册看不了），塞金句进去也救不了长廊的路人体验；而金句墙夹在统计帧中间，传播动线（读→赞→转）也展不开。

**金句墙的独立可供性闭环**：读（被戳中）→ 赞（零成本表达）→ 分享（把这句/这墙转出去）→「我也报过名？」找回转化 /「这是什么活动？」认知 CGC。每一环都对路人开放，无一环要求身份——这是裂变引擎的标准形状。

## 调研结论（选型已定，写进提示词）

**C · 山河图谱 → 用 ECharts**（`echarts` Apache-2.0，周下载 3.69M；`echarts-for-react`）：geo 组件 + `effectScatter` 涟漪散点（点赞数映射光晕）+ `lines` 流动脉络全是现成的；且它是**唯一能同构到小程序的生产路径**（`echarts-for-weixin` 的 ec-canvas 走 canvas）。关键坑也查清了：ECharts 5+ 不内置中国地图，用阿里 DataV GeoAtlas 的 geojson 简化后内联，**南海诸岛 feature 不能过滤**（地图合规）。被淘汰的：AntV L7（杀鸡用牛刀）、Mapbox GL v2+（专有许可证，触红线）、react-simple-maps（SVG 进不了小程序）。
