# 愿望归属登录账号，历史档案关联可选

闪念间允许没有历史档案的新用户许愿，因此新愿望以 `user_id` 为账号归属，`person_id` 仅为可选档案关联；不创建占位 Person。存量仅关联 Person 的愿望及有效 token 写入口继续表达真实的历史作者身份，认领后按该 Person 的账号归属展示、授权和合并年度额度。

年度额度统计账号愿望与其已认领的历史愿望（包括软删）；写入在同一事务按 Person → User 顺序加锁，避免两个入口各获 3 次额度。新小程序提交带稳定 requestId，同账号同请求重放返回原记录，改动正文或选项必须换请求号。账号注销级联删除其愿望；档案删除只清理关联该档案的愿望，独立账号愿望不受影响。

迁移新增的作者 CHECK 与外键分开验证、索引并发创建，不做大表回填。产生无档案愿望后，回滚到 person_id 必填会明确拒绝，需前向修复，不能丢弃用户内容。客户端仅把登录草稿交接给本次返回的账号，日常草稿按账号隔离；第二批 2A 不新增独立许愿树浏览页。
