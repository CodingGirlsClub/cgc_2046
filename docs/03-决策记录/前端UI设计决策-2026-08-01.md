## 决策清单

### U1. workspace-select 详情区选中态

**状态**：✅（用户已拍板，2026-08-01）

**决策内容**：
- 正式版工作台选择页采用 **B 侧栏 + 详情区** 形态，侧栏列表需支持**选中 state**（selected 高亮），详情区**跟随选中项展示**对应工作区详情。
- 详情区需覆盖**含 pending/invited 中间态卡**的展示（与 join_policy 三态 UI 区分一致，见原型验证结论 #1）——选中「申请审批中」或「待凭据加入」的工作区时，详情区展示对应中间态卡，而非仅 active 工作区。
- 当前原型仅默认展示 active 工作区、无选中态切换交互，为原型简化，**不作为正式版行为**。

**影响面**：
- 页面：工作台选择页（Workspace Select）——侧栏列表组件需支持 `selected` state；详情区按选中项渲染（active 卡 / pending 卡「申请审批中」/ invited 卡「待凭据加入」）。
- 组件：侧栏列表项（workspace-list-item）选中态样式 + 详情区（workspace-detail）按状态分支渲染；与 Web 功能清单「Workspace 设置页」「成员管理」中间态表达对齐。
- 数据：详情区数据源 = 当前用户可见的 Workspace 列表（含 membership 中间态：JoinRequest pending / Invitation invited），需后端在列表接口返回 membership 状态。

### U2. Owner 角色不可行内授予

**状态**：✅（用户已拍板，2026-08-01）

**决策内容**：
- **Owner 角色不可在成员管理页行内授予/编辑**——成员管理页的角色操作（行内下拉/切换）仅覆盖 Owner 以下角色。
- Owner 的授予/变更仅允许**平台管理员或现有 Owner 指派**（管理动作，走专门指派流程，不经行内编辑）。
- 原型已按此限制实现；正式版 **Rbac 与成员管理 UI 遵循**该约束。

**影响面**：
- 页面：成员管理页（Members）——角色列不可行内授予 Owner；Owner 指派走独立入口（平台管理员 / 现有 Owner）。
- 组件：角色选择控件（role-select）需排除 Owner 选项（行内场景）；成员表格行内编辑仅限 Owner 以下。
- 后端约束：RBAC 权限判定——行内改角色接口对 Owner 目标拒绝（仅平台管理员 / 现有 Owner 的专门指派接口可写 Owner）；与领域模型定稿角色枚举（owner/admin/…）一致。

### U3. 主题切换改用户偏好设置

**状态**：✅（用户已拍板，2026-08-01）

**决策内容**：
- 正式版 **Dark/Light 主题切换存用户偏好设置**（按用户持久化），而非原型阶段用的 `?theme=` URL 参数 + 底栏按钮。
- 原型阶段的 `?theme=` URL 参数 + 底栏切换按钮机制**保留作为开发期工具**（便于原型/开发调试），不进入正式用户交互路径。

**影响面**：
- 页面：全局主题（Dark/Light）——由用户偏好设置驱动，登录后按持久化值应用。
- 组件：主题切换入口（设置页内，非底栏原型按钮）；开发期保留 `?theme=` 参数作为调试手段。
- 后端约束：用户偏好设置需持久化（用户级字段或偏好表），主题值随用户会话/接口返回；原型底栏按钮在正式版隐藏。

### U4. PrototypeSwitcher 浮动栏正式版移除

**状态**：✅（用户已拍板，2026-08-01）

**决策内容**：
- 浮动栏（**PROTOTYPE 栏 / 变体切换器**）为**纯原型工具**，正式版**生产构建必须隐藏/移除**，不参与正式 UI。
- 与既有约束一致：生产构建自动隐藏 PROTOTYPE 浮动栏（原型验证结论 #5，见 `用户旅程与Web功能清单.md` §3 工程约束）。

**影响面**：
- 页面：全站（浮动栏为全局叠加层）——生产构建移除。
- 组件：PrototypeSwitcher / 变体切换器组件——仅开发/原型环境渲染，生产构建 tree-shake 或条件隐藏。
- 工程约束：前端构建配置（环境变量 gate，如 `VITE_PROTOTYPE_ENABLED`），正式版构建默认关闭；与 Web 功能清单 §3 工程约束、总纲 §7.2 M3 前端约束行对齐。
