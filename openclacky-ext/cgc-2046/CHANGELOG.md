# Changelog

本扩展面向用户的更新记录。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)；版本号见 `ext.yml`。

## [Unreleased]

### 变更

- **分发渠道转自托管**：扩展不再发布到公共 Extension Marketplace。安装改为一条命令 `openclacky ext install https://api.codingirlsclub.com/ext/cgc-2046.zip`（zip 由 CGC-2046 官方后端分发，与网站同可用性）。已安装用户不受影响。
- 面板「升级」按钮改查 CGC 自有版本端点（`/api/ext/cgc-2046/update_info` 透传），升级链路不依赖市场。

### 新增

- hub 面板右上角版本徽标与「升级」按钮：有新版本时一键升级。
- 工作台管理侧栏支持活动管理：新增活动创建等 MCP 工具，供给区按状态提供发布 / 取消 / 结束动作。
- 管理侧栏供给行展开区：课程与活动的对象级操作排（发布、取消、结束、对话修改、网站编辑深链）。
- 课程学习内容按章节分组展示。

### 改进

- 管理侧栏改为工作台实时投影：角色、待办、供给变化即时反映，后台授五回前台即生效。
- 订单区改注意力面：只显示需要处理的非终态订单（退款失败置顶，最多 5 行），历史订单改走助手或网站。
- 最近会话支持三助手 Tab 过滤，会话列表上限提升到 20 条。
- 课程与活动条目用固定语义色徽章区分；管理侧栏「供给」统一改称「课程与活动」。
- 连接引导精简为面板一键连接（自动打开网站、签发 token、安全写入），细节下沉到 skill 参考文档。
- 连接引导支持环境自举：缺 node（或版本低于 22）导致 browser 自动连接不可用时，助手先按用户系统自行安装运行环境并验证，不再直接降级到手工 token 流程。

### 安全

- 扩展 API 全面加固：本机 Host 头校验（防 DNS rebinding）、Origin 全匹配（scheme+host+port）、connect 请求的 token/URL 字符集校验。
- 面板对用户生成内容与服务端异常数据做注入中和与健壮性处理；自动注入的处理指令改用固定动作 + 记录 id，不拼接用户可控文本。
- 面板外链（网站地址、深链、支付链接）统一过 scheme 校验：仅放行 https 与本机调试地址。
- `mcp.json` 统一收紧为 0600 权限；错误上报先脱敏再截断；重连 / 断开时清理过期 MCP 连接。
- 分发包只含 git 跟踪的干净文件集，打包时校验 zip manifest。

### 修复

- 面板按钮与徽章样式接入宿主设计系统：按钮统一改用宿主全局类（`btn-primary` / `btn-secondary`，hover / 禁用态与品牌色随宿主主题自动跟随），面板底色与文字改消费宿主 `--color-*` 变量。修复「刷新 / 返回 / 取消」等按钮退化为浏览器默认灰底样式、多处面板浅底色因引用宿主不存在的变量而失效（背景透明）的问题。
- 修复工具调用参数为 JSON 字符串时事件钩子崩溃的问题。
- 修复供给区课程与活动数据其一失败时整区不可用的问题（错误隔离）。

## [0.1.0] - 2026-09-06

首次发布：把 CGC-2046 平台接入 OpenClacky。

### 连接管理

- 面板「连接网站」一键连接：助手接管已登录浏览器，自动签发一次性 token 并经安全管道写入，token 不进对话与会话记录。
- 自动连接不可用时支持手动 token（剪贴板管道 / 临时文件 / 对话粘贴三级 fallback，含 token 形态校验）。
- `~/.clacky/mcp.json` 原子化写入（0600 权限、并发保护、失败回滚），不影响其它 MCP 服务条目；面板一键断开连接。
- 连接状态实时展示；MCP 连接出错时面板显示异常横幅。

### 助手

- **CGC-2046 助手**（全员）：工作台问答、成员与活动课程查询、学习陪伴。
- **CGC 教研助手**（tutor）：课程教研共创、草稿版本管理、教研流程。
- **CGC 管理助手**（owner / admin）：创建课程、审批、邀请成员（含预授权角色与自动指派）、订单处理。
- 助手启动时自动拉取角色匹配的最新 playbook 并展示版本；tutor / admin 为安全薄壳，方法由平台统一下发。

### 面板

- **程序媛汇 2046** hub：连接状态、身份与工作台切换、我的任务（可点击跳转）、按角色的功能目录、最近会话。
- **课程学习**：课程地图、学习单元草稿编辑、待复习队列。
- **发现**：公开活动与课程浏览、报名、支付轮询；已截止报名显示徽标。
- **学习地图**（助手会话侧栏）：目标进度、待复习、一键注入学习指令、断点续学卡。
- **教研工作台**：结构化草稿编辑器（目标校验、首存规则）、prep 流程引导。
- **教研产出**（教研会话侧栏）：草稿树、版本、质量报告、流程状态实时同步。
- **工作台管理**（管理会话侧栏）：跨工作台待办审批、课程与活动供给、订单、按域快捷入口与网站深链。

### 学习闭环

- 复习调度（待复习队列）与学习分析。
- 课程内容按学习目标组织，材料随目标直达。

### 其他

- 教研配套视频执行物料（场景模板、环境自检、TTS 脚本、品牌素材）。
- 公开市场发布准备：v0.1.0 版本号、skill 明文分发、生产 URL 默认值。
