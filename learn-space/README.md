# CGC 学习空间

这是 CGC-2046 平台的「学习空间」：一个装在你自己电脑上的小文件夹，让 opencode（AI 助手应用）能连接 CGC 平台，陪你学习课程、整理教研内容、处理工作台事务。

## 使用方法

1. 把下载的 `learn-space.zip` 解压出的 `CGC-2046` 文件夹放到「文稿」（Documents）目录下，最终路径是 `Documents/CGC-2046/`。建议把 `learn-space.zip` 也放在这个文件夹里，连接自检可以用它校验文件是否完整。
2. 打开 opencode 应用，选择「打开文件夹」，选中 `Documents/CGC-2046/`。
3. 第一次使用时，会自动打开浏览器请你登录 CGC 账号并确认授权；完成后回到 opencode 即可开始。
4. 在会话里输入 `/cgc-status` 可以随时检查连接状态与版本。

## 卡住了怎么办

- 提示需要重新授权：回到 CGC 网站的引导页，重新走一遍连接步骤。
- 输入命令没有反应：完全退出 opencode 再重新打开一次（配置更改后需要重启生效）。
- 提示版本过旧：到 CGC 网站的引导页重新下载最新版的学习空间。

## 文件说明

- `opencode.json` —— 平台连接与安全设置（不含任何密码或密钥）。
- `AGENTS.md` —— 给 AI 助手的本地约定。
- `.opencode/commands/` —— 可用命令：`/cgc-status`（连接自检）、`/cgc-learn`（开始学习）、`/cgc-curriculum`（教研）、`/cgc-admin`（工作台管理）。
- `VERSION` —— 当前包版本。

## 卸载

1. 删除 `Documents/CGC-2046/` 文件夹。
2. 到 CGC 网站「账号设置 → 连接与授权」撤销本次授权（撤销即时生效）。
3. 打开 opencode，在连接 / MCP 设置里对 `cgc-2046` 执行登出、清除本地保存的凭证（桌面设置，或命令行 `opencode mcp logout cgc-2046`）。

在共用电脑上使用后，请务必完成第 2、3 步。
