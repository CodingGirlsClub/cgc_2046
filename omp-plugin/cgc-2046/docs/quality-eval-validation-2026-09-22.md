# 判据化质检评审 — 真机验证报告（2026-09-22）

对象：某已发布课程 43 卡 v9 草稿（历史人工六视角审核报告为 ground truth：11 minor + 2 报告级瑕疵）。评审全程未调用平台写工具。

## 验证轮次与结果

### 第一轮：全文 bool 判据（失败，教训定型）

5 判据（锚点格式/未锚定断言/英文残留/checklist 可判定/story 完整）× 43 卡，每卡全文一个 state。

| 判据 | 结果 | 判定 |
|---|---|---|
| checklist / story | 43/43 全过 | ✓ 正确（发布版质量高，无误报） |
| 未锚定断言 | 43/43 全报 true | ✗ 区分度为零 |
| 英文残留 | 43/43 全报 true | ✗ 区分度为零 |
| 锚点格式（judge 判） | 43/43 全过 | ✗ 漏报（实有 12 行 en-dash 锚点） |

**教训**：全文 bool 语义项判据在该类语料上必然全中（正文天然充满年份数字与英文术语）；格式类判据交 judge 会漏报。43 卡 5 判据 3.3s、jev 全程真判（model: typesafe/jev-1.13.0）。

### 第二轮：两段式 triage（召回可行，精度不足 → 定位为嫌疑层）

grep 预筛候选 → judge_batch 逐候选 choice 二分：

| 批 | 候选量 | 靶子 | 结果 |
|---|---|---|---|
| 英文残留（词级） | 324 词 | successive（已知 minor） | ✓ 捞出；但共报 40+ 词，precision ~3%，大量术语/专名/公式变量误报 |
| 无出处统计句 | 81 句 | 「对照组约 20%」（已知 minor） | ✗ 被研究名语境掩护判 attributed（预期盲区）；66/81 报 unattributed，多为页级锚点覆盖的合法句 |
| 未定义缩写 | 61 个 | DADI（已知 minor） | ✗ 被 DSAT 括号展开误覆盖；另误报公式参数名（OFF/KS）/罗马数字 |

**教训**：L2 只能是 triage——省人裁量（43 卡 324 词 → 40 嫌疑，省 87%），不能定罪。另发现预筛 bug：markdown 加粗打断「约 **100 小时**」的正则相邻性，预筛模式必须容错 `**`。

## 定型架构（已固化进 `skills/cgc-quality-eval/SKILL.md`）

- **L1 确定性 grep**：格式类判据终判（锚点 en-dash 12 行 = ground truth 29 锚，100% 精准，零 judge 成本）。
- **L2 两段式 triage**：grep 候选 → judge_batch 逐候选，产出待人裁嫌疑清单，永不定罪。
- **L3 教材配对终判**：锚点页原文为 state、逐声明 noul，书外声明实锤层。

## 成本

四轮共 ~500 个 judge 判断，全部秒级返回（0.4–10s/批），估算总成本 **<$0.01**（jev $0.042/Mtok）。
