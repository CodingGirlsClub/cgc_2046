# Changelog

小程序面向用户的更新记录。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

**版本号单源 = 本目录 `package.json` 的 `version`**，与微信平台上传的版本号一致；版本序列按语义递增：功能专题 minor +1（0.1.x → 0.2.0），小修 patch +1。线上版本历史（发布时间、审核备注）以 MP 后台「版本管理」为准；本文件记录变更内容。发版步骤见 [README.md](./README.md)。

## [0.2.0] - 2026-09-25

### 新增（闪念间）

- **公共许愿树**：游客可浏览许愿树与闪念回溯体验；无历史档案的账号同样可以许愿。
- **闪念之声墙**：原生声音墙，支持按城市浏览。
- **长廊回响卡**：长廊卡片新增「有回响」标记（#837）。
- **圆梦名册**：圆梦线进入名册（按 applied_at 混排），名册徽标「当年报了名」。

### 变更

- 金额文案统一：¥ 与数字之间加空格（押金 / 收费 / 审批金额）。

## [0.1.1] - 2026-09-19

### 新增

- **招募流**：职位批次浏览 → 两步网申（含简历上传，全仓首个文件上传机制）→「我的申请」进度跟踪。
- **hackerstart-1024 活动专页**：campaign 页 + 发现页入口卡；品牌段改版 Partnership（五项收益阶梯）+ 押金 87 元。
- **公开主理人展示**：活动详情页「活动信息」区新增「主理人」行（#538）——后端 `publicModerators` 投影单源（三端同口径），displayName 缺失回退成员编号（CGC-XXXXXX）；无主理人不渲染该行。
- **主理人订阅双键**：活动详情页主理人订阅按钮扩为「订阅主理人指派与变动通知」两开关（指派 + 移除，#538；SubscriptionScenario 19→20）；移除通知点开深链回活动详情页，公开主理人投影即「名单里没有我了」的对照面。

### 修复

- **押金面四件收口**：确认弹框金额快照化、金额现值权威口径、同意留痕落库（#748–#751）。
- **押金同意门后端下沉**：`createOrder` 校验挪到后端，小程序创单时机对齐（#727）——绕过前端同意门直接创单不再可能。

### 变更

- 「开班」术语统一为「成班」（#625）。
- 订阅触点 7 处 handler 收敛为注入式 domain helper（#693，内部重构）。

## [0.1.0] - 2026-09-17

> **未单独发布**：审核通过后未点发布，线上没有这个版本号；内容已全部包含在 [0.1.1](#011---2026-09-19) 及后续版本中随其上线。

### 新增

- **现场核销**：主理人在 `check-in` 页扫码核销参与者（#508-A 主路径）；参与者在详情页出示核销二维码，核销成功文案按押金单真实状态显示。
- **订阅消息触点扩展**：SubscriptionScenario 1→11（含核销码通知 `enrollment_check_in_code` 带码下发、主理人指派通知深链）；构建期模板 ID 注入。
- **年龄门槛门控**：报名表单新增年龄校验，三入口同一扇门并留痕（#510）。
- **我的报名读面**：列表补活动开始时间（startsAt）与场地（venue）。

### 修复

- **押金支付同意门**：押金单在「立即支付」前必须明示「押金 ¥xx（到场退）+ 未到场不退」并显式勾选同意；判据只认订单自己的金额快照，不用活动实时配置（U1，与 web 收银框同源）。
- **分享深链**：initiative 公开分享链接可达；`slug` 深链冷启动直达 initiative-detail（此前 slug 被静默丢弃停在首页）；event-detail 回链与徽章口径对齐，热启动按 id 去重。
- **归档场门禁**：归档活动不再渲染报名表单（status + badge 双门）；截止后保留已报名入口（closed≠结束，按 endsAt 分桶文案）。
- **取消与退款披露**：取消弹窗文案与押金自动退款行为对齐；定价场取消退款规则四处披露（条款 5.2 分模式重写）。
- 押金金额守卫拒 0/负数；核销页押金提示按 depositEnabled 门控。

### 变更

- Initiative 生命周期：新增 cancelled 状态 + close/cancel 守卫 + window_ends_at worker（#628）。
