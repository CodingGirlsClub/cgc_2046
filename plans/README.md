## Findings considered and rejected

(Recorded so the next audit doesn't re-raise them.)

- **期待按钮重复提交**：已有 `pending` Set 防重（`wishes-wall.tsx` toggleExpect）——by design，非发现。
- **期待乐观回滚吞并发**：#806 F2 修复已落地（按 wishId 函数式回滚 + 服务端校正），测试覆盖——非发现。
- **附议 mutation document 签名不匹配**：`FLASHBACK_ENDORSE_WISH` document 已更新为新签名（wishId/contributionTypes/message/notify），服务端多余 variables 被忽略——误报；真问题是 003 的静默失败。
- **corridor 树双 UI 并存是技术债**：设计文档（`docs/plans/2026-09-21-1945-feat-flashback-wishes-tree-plan.md`）拍板长廊成员面维持 + 公开树独立路由——有意架构，非债。
- **城市过滤包含 `city IS NULL` 愿望**（`wish_public.ex` `is_nil(w.city) or w.city == ^city`）：疑似有意（不因筛选隐藏无期望地的愿望），但无注释。⚠️ 待产品确认：若确属设计，加一行注释钉死；若不是，另行立项——本批未动（006 明确列为 STOP 条件）。
- **「换一批」不保证覆盖全部愿望**（前端 `limit:60` 固定、后端 `offset` 就绪未接）：KTD10 加权随机语义下「重洗探索」与「穷举」是两种产品选择；当前愿望量级（百级）无碍。量级上千后再评估接 offset 翻页——现在不做。
- **分享链接丢 locale 前缀**（`copyShareLink` 拼 `/flashback/wishes` 裸路径）：打开方靠 `cgc_locale` cookie（1 年）与默认 zh-CN 兜底，产品默认中文可接受——不修。
- **schema `flashback_endorse_wish` 无 RateLimit middleware**：频控在 `WishExpectations.set_expectation` 内部双窗（voter 30/min + IP 60/h），与 likes.ex 同规格——by design。
- **举报弹层无 Esc 关闭 / focus trap**：全站 dialog 模式一致（corridor 模态同款），单独给 wishes 加会制造不一致；留作全站 a11y 专项——本批不做。
